# Bundled fonts (AST-003)

The game draws all text with these TrueType fonts. They are not RCT or OpenRCT2 assets.

| File | Font | Used for | Licence |
|---|---|---|---|
| `Jersey10-Regular.ttf` | Jersey 10 by Sarah Cadigan-Fried (The Soft Type Project) | small and medium text | SIL OFL 1.1, see `Jersey10-OFL.txt` |
| `Micro5-Regular.ttf` | Micro 5 by Sarah Cadigan-Fried (The Soft Type Project) | tiny text | SIL OFL 1.1, see `Micro5-OFL.txt` |

Source: https://github.com/google/fonts (`ofl/jersey10`, `ofl/micro5`), unmodified.
